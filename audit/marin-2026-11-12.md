## A proposed audit checks which benchmark records appear in Hero training data (2026-11-12)

Marin proposed a tool to find exact text copies of benchmark records in the Hero data store. It distinguishes documents that survived filtering from documents that were discarded, which matters when assessing possible benchmark exposure. The open PR reports a run over stack-v3 for GSM8K, HumanEval and MMLU with manual spot checks. It looks for all searched fields in one normalized document and checks the store’s filtering metadata. Short or generic text can match by coincidence, and this method misses paraphrases. The PR supplies a method and test scope. It does not establish a contamination rate for the released model or quantify an effect on evaluation scores.
