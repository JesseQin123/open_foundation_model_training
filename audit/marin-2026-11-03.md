### A merged fix preserves the intended counts in a training mixture

Marin accepted a fix for a rounding error that could silently give one data source an example intended for another. The code protects exact counts when the requested mixture implies a whole number of examples. PR #10793 merged November 3 at 01:59 UTC. In the reproduction, 1001 divided by 64000 and multiplied back evaluates just below 1001, so truncation allocated one fewer example before remainder assignment. The patch snaps values within 1e-9 of an integer before allocation. The PR reports 23 passing mixture tests. Configurations hitting this boundary can select a different sequence when restarted on the new code. Current Hero adoption and any impact on model scores remain unverified.
